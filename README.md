# WindowAligner

Небольшая программа для Windows, которая перемещает выбранное окно в центр или к нижнему краю экрана. Подходит для игр и других приложений в обычном оконном режиме.

## Пример использования

Я играю на большом 4K-телевизоре, но запускаю игры в оконном режиме с соотношением сторон 21:9. Для удобства я опускаю окно игры к нижнему краю экрана и выравниваю его по центру. Так изображение остаётся широким, а положение окна каждый раз получается точным без ручного перетаскивания.

## Запуск

1. Скачайте `Align-Window.ps1` и `Запустить выравнивание.cmd` в одну папку.
2. Дважды щёлкните `Запустить выравнивание.cmd`.
3. Выберите окно из списка и нажмите **«Выровнять по центру»** или **«Выровнять по низу»**.

Кнопка **«Обновить»** добавляет окна, открытые после запуска программы.

Можно запустить скрипт напрямую из Windows PowerShell 5.1:

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Align-Window.ps1
```

## Как работает

Программа определяет монитор выбранного окна и его рабочую область с учётом панели задач. При выравнивании сохраняются текущий размер окна, его активность и порядок окон. Координаты рассчитываются заново при каждом нажатии, поэтому фиксированное разрешение экрана или окна не требуется.

Для перемещения используются Win32 API через `Add-Type`. На системах с несколькими мониторами учитываются и отрицательные координаты. По возможности используется режим DPI awareness для каждого монитора.

Свернутое окно нужно восстановить перед выравниванием. Некоторые игры в полноэкранном режиме или с защитой от внешнего управления могут не разрешать перемещение окна.

Программа не устанавливает дополнительных компонентов и не требует прав администратора в обычном случае. Если целевое приложение запущено с повышенными правами, для управления его окном может потребоваться запустить программу с теми же правами.
